# Task 01 — Your first weather card (no API)

## Objective
Learn how JSX, React components and props work.

## Your challenge
With the tutor's guidance, scaffold a Vite React app in `frontend/`, then build a simple, static weather card displaying *sample data*:

- City: Kolkata
- Temperature: 28°C
- Condition: Sunny
- Humidity: 65%

Split the UI into **at least two React components**, and pass one or more values as props. Use basic CSS. Do not fetch live weather or implement state, search, or effects yet.

## Success criteria
- `npm run dev` starts the React app.
- You can explain what a component is and how JSX differs from plain HTML.
- You can identify where props are passed and received.
- You wrote the code yourself, without pasting a generated solution.

## Check your understanding
1. Why do component names start with uppercase letters?
2. What is the difference between a JSX expression and a string?
3. Why split a page into smaller components?

Only after completing this task move on to state and events.
