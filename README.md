# Weather App — React + Node Learning Lab

This repository is for learning **JavaScript, React, and basic Node.js/Express** by building a weather application step by step.

**Learning rule:** The human writes the application code. Coding agents teach, give hints, and review rather than building the app for the learner.

## Roadmap
1. JavaScript fundamentals: variables, objects, arrays, functions, modules, promises, and fetch.
2. HTML/CSS basics: semantic elements, forms, box model, and Flexbox.
3. React basics: JSX, components, props, state, events, conditional rendering, lists, and effects.
4. Live weather: API requests, loading/error handling, and forecast cards.
5. Node.js + Express: endpoints, middleware, validation, CORS, and errors.

Start by reading [AGENTS.md](AGENTS.md), [Claude Code guidance](CLAUDE.md), and the [first exercise](tasks/01-first-weather-card.md). Track progress in [docs/PROGRESS.md](docs/PROGRESS.md). We will use React + Vite with JavaScript and plain CSS. Add backend only after React foundations.
